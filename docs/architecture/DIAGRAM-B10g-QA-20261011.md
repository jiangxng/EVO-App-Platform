# B10g | Privacy-safe Chrome error counts
Before B10g the synthetic/authorized browser proof returned raw `window.__errors` strings in summary JSON, and assertion failures might echo an unredacted browser exception. Replaces those with integer `errorCount`, checks zero with numeric assertions and never serializes raw captured error strings. This safeguards private client labels that could appear in error messages. True local user data remains unprovided; frontend Host replies can still contain data and independent security audit is pending. CI covers synthetic S2C/P2P/probe. Formal §14 not signed.
