# B8i — 自环对非关联连线、标签的局部避让及稳定取景（2026-10-10）

## 交接、依据与实现边界

- 只继承此前已留存的产品研究决策、设计规范、[商业化接收矩阵及交接 PR #552](https://github.com/jiangxng/EVO-App-Platform/pull/552)，本轮没有重新查阅新的网络原文；参考网址及上轮推断不能冒充本轮核验结果。
- Eidos [B8h Draft #149](https://github.com/jiangxng/eidos/pull/149) 和 EVO [B8h Draft #596](https://github.com/jiangxng/EVO-App-Platform/pull/596) 是已经验证通过的基线；本轮独立 [Eidos B8i #150](https://github.com/jiangxng/eidos/pull/150)、[EVO B8i #597](https://github.com/jiangxng/EVO-App-Platform/pull/597)，两者只堆叠各自 B8h 分支。无 main 合并或生产部署。
- 自动排版/路由属于图形固定功能，不交给 Agent 模拟鼠标。只变更投影展示层，绝不改变业务关系端点、实际箭头、定义历史 revision、Host CAS 或访问权限；既有 44 CSS px 热区不收缩。

## 已选择方案

1. **稳定的非关联连线占用**：从渲染时的图数据构造不与自环源节点直接关联的其它关系线段：自动/旧直线使用两端节点中心形成的线段；存在手工 waypoint 时用中心—控制点—中心分段。利用 Liang–Barsky 线段与矩形判交，对自环每个候选方向的*节点外侧*控制柄走廊计算穿越次数（权重 6000/次）。这样不会把自环本节点内部及进入该节点的关联关系错误当作需要绕开的外部障碍。
2. **标签预留而非鼠标瞬态 DOM**：为其它非关联关系的标题与观察值文字估计稳定的文字矩形：字号约 11、单字平均 6.2 世界单位，宽度 24～176，位置取源/目标端点中点（非选中状态也预留）。可避免放大缩小或点击时因为 DOM 标签短暂显示/隐藏导致自动路线跳边。标签矩形相交面积按 2 倍权重参与方向评估。
3. **遵循 B8g/B8h 优先级**：四侧分别综合可见节点占用、同侧已分配自环、其它关系线的穿越次数和标签面积；同分仍按右→下→左→上。已保存手工自环只按自身 waypoints 重绘，不因邻接关系/标签变化而跳侧；从右侧改走其他方向后仍可原生鼠标拖动、取消、Undo/Redo、显式保存。若四侧仍冲突，则沿用 B8h 拥堵警示，不能误称无交叉。
4. **确定性的画布 Fit 范围**：新增 `diagramSelfLoopFitBoundsV010`，当可见显式自环存在时，将外侧默认 reach、同一节点 5 条及更多自环向外加层距离、手工路径世界坐标及周围控制柄余量纳入 Fit All/ Fit Selection；没有显式自环的旧图范围保持历史一致。它不读取相机缩放或平移作为自动布线输入，从而不产生 pan/zoom 跳动。
5. **性能预算**：渲染级缓存每个有自环节点的“其它非关联线段/标签”计算。当前仅在可见关系不超过 1500 且自环归属节点不超过 48 时采用墨迹惩罚；更高密度降级为 B8h 的节点/同节点自环避让。本预算不是全局索引替代品；下一阶段需要线段/标签空间索引和可靠性基准，不能声称全图无交叉。

## 比较、限制和未决

- 采用图数据确定性矩形/线段估计，排除根据“鼠标悬停显示的 DOM 标签”作路线依据；后者会在点击/缩放时让几何闪烁。
- 排除改写、重算用户已手动保存的线条；其端点和 waypoints 是展示层既有独立契约，不能被全自动推荐重置。
- *其它业务连线的几何仍是保守近似*：已保存 waypoint 近似较好，自动圆角/正交/曲线的完整 Bézier 曲线没有完全计算交点；标签面积是文字宽度估计值，不保证真实浏览器字体精确包围。
- 四侧拥堵时仍选评分最低一侧并警示，未实现复杂全图寻路、边边全局最优、文本实际测量防碰撞、连接器端点的所有切线冲突、多端设备联调。
- 当前视口改进限 **Fit All 和 Fit Selection 的包围范围**，不保证任意用户手动 pan/zoom 后外侧手柄都在视口内。实体 iOS/Android/macOS/Windows、数据库进程重启和完整 §14 39 项仍 **NOT TESTED**。

## 验证计划与证据

- 专项 Node/Eidos/App CI：右侧竖向其它关系线迫使自动自环改走下侧；只有标签矩形也能改道；四方向都被跨线时真实标拥堵；数据输入无效拒绝；障碍重排不改变结果；保存过的手工自环不跳边；普通旧图 Fit 范围不变；自环外侧的新增/已保存路径不会被 Fit 裁掉。
- Chrome/154 B8i 专项从 B8h **23标签页** 扩为 **26标签页**，隔离注入测试线段、另一线段的长标题，分别验证真实 Designer DOM、自环 44 CSS px 原生鼠标移动/取消、真正只读 Viewer 同一 SVG、标签独立避让。测试用 synthetic artifact source **不表示生产业务关系已接入**。最终结论必须以 B8i 最新 CI PASS 为准，未运行或失败时不得写成已通过。
- 39 项商用验收继续逐项待测，不能借一个浏览器标记直接判定正式商用。
