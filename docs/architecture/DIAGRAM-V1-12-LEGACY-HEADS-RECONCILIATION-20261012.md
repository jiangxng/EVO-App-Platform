## Non-shipping archive semantics

- Older unmerged heads may contain valid ideas. Only the listed browser proofs/relocated current modules are demonstrably subsumed. Historical parentage protects the **complete source of the seven product-era branches**, including deliberately unported old-only UI. **No new product feature is silently claimed merged**.
- The audit branch performs an `ours` **history-only integration**: leave main's compiled/runtime tree unchanged; append the twelve exact legacy heads as Git parents; add this explanatory document and exact SHA retirement workflow. Git history and code can be retrieved from commit SHAs after deleting branch labels.
- The #388 PR has remained open since early October. Close it **only after** history-only integration reaches main and after checking head SHA, ownership and new main ancestry. This closure means **superseded/rejected for v1.0**, not “the original PR code was deployed.”
- All refs are deleted with exact-SHA leases, new main ancestry confirmation, no open PR head/base (after closing explicitly identified #388), protected-branch denial and explicit allowlist. Never delete or modify other-window Agent, Ledger, TR-01, external Eidos refs.
- This document records what could not be safely ported. The user may separately commission the software Projection Gallery, optional Eidos `secondaryActions`, and Viewer back navigation as new scoped features. Do not silently represent them as shipped by the retirement process.
