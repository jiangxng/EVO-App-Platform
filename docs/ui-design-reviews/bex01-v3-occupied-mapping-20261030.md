# BEX-01 V3 字段占用状态

## 目标与完成条件

企业导入操作人在字段核对页打开任一映射下拉框，能看到哪些目标字段已被别的来源列占用，同时无法重复选择。保存、预检查、创建字段和正式导入继续由真实 Host 操作与权限决定。

## 流程与步骤

复用当前导入任务的四列映射表。已保存/恢复的映射先显示；选项中的占用状态随同页更改即时更新；释放后的字段恢复可选。选择“新建字段”仍走现有审核，随后预检查并明确提交。V3 原型 `fillMappings()` 是本轮占用交互依据，demo 假保存不移植。

## 导航与信息架构

仍为 Data Import 任务内的映射工作台，导航层为 contextual work；无新菜单、页面、卡片或主操作。唯一主要操作仍是保存映射并继续预检查。占用原因紧贴下拉候选，避免跨列寻找。

## 视觉与颜色

沿用 Eidos 原生 select、字段表、既有 Business Office 色板和焦点。被占用项用浏览器原生禁用态和“已占用”文字表达，不增设新颜色或改变行高。V3 对照仅涉及候选的语义状态。

## 记忆与注意力

已占用候选仍可见，操作者不用记住其他列用了什么字段。现有来源样本、保存状态、返回映射和失败恢复保留；合法的旧冲突选择不被客户端静默改写，由 Host 拒绝并提示修复。

## 无障碍与跨年龄

保留原生 select 键盘操作、屏幕阅读器禁用语义与文字状态，不靠颜色单独辨识。桌面和 390px 窄屏共用逻辑，控件触控高度遵守 Eidos 现有规则。

## 安全与数据修复

本地禁用仅是交互反馈；Host 仍校验唯一映射、企业权限和来源修订。重复映射、权限拒绝或预检查失败均保留任务及原文件，允许回到映射页纠正。没有新增自动写入或 Agent 依赖。

## 证据与剩余问题

原型固定 blob `9f57e9320eb527786ff7b737be27777eba6f8a92`，路径 `docs/plans/foundation-list-experience/BEX-01-IMPORT-V3-IN-CONTEXT-HIGH-FIDELITY-20261015.html`，`fillMappings()` 对其他列占用的 option 使用 `disabled` 与 `· 已占用`。根因是 `vendor/eidos/src/app-host/page-controller.ts` 原先直接过滤这些候选，`apps/data-import/page.ts` 未声明占用文案。通用语义来自已合并的 Eidos PR #206（merge `04015aeb`），本仓只移植对应的三处 Eidos 语义差异并配置双语文案。`npm run build`、两份定向协议测试 13/13 通过；真实浏览器检查被本地浏览器授权审核拒绝，不能记为浏览器 PASS。

## 页面模式与导航归属

Eidos 现有 Form / Review Table 工作台；Data Import 任务内的字段映射，不新增路由或导航。接入通用 Eidos `exclusiveSelect.occupiedLabel`，Platform 只提供中文/英文业务文案。

## 功能、布局、颜色对照

功能：V3 显示被其他列占用的候选、禁用并标注；现有实现隐藏候选。本轮修复此差异，Host 服务端重复映射校验保持。

布局：V3 与当前均在对应系统字段下拉框里做决定；不改表格结构、列宽和行高。

颜色：沿用现有 Eidos 选项禁用态、原型既有蓝色焦点与白色表面；不新建色值。真实渲染待浏览器核对。

## 入口、退出与恢复矩阵

| 上下文 | 入口 → 操作 → 目标 | 返回父级 | 取消/异常恢复 |
| --- | --- | --- | --- |
| 企业有资格操作者 | 导入任务映射页 → 查看/更改占用候选 → 保存并预检查 | 预检查页返回同一任务映射 | 取消/失败后来源和映射保留，释放的候选可再选 |
| 普通成员/无资格 | 映射页只显示授权能力；禁止无权创建字段 | 返回导入目录 | Host 拒绝越权写入，原文件不变 |

退出：返回导入目录，或继续预检查与明确导入。

异常恢复：已有 Host 失败路径保留 Import Job 与来源证据；本轮验证改选释放和重置后重新占用。
