## 目标与完成条件

已获授权的企业导入负责人在真实 Excel 缺失的 `subjectType` 字段附近选择正确主体身份，保存后重新检查；原文件不可被无痕篡改，最后提交仍独立确认。样例代码中三条空值属**合成测试数据**，不代表客户三行实际身份。

## 流程与步骤

用户从 #921 未完成任务→#925 来源/异常核对→单行“修正本行问题”→本行上下文表单选择合法身份→保存并真实 dry-run→剩余问题或明确 commit。已更正值可撤销重检。操作是确定性按钮，不强制调用 Agent。

## 导航与信息架构

新增 Data Import 自身 `/data-import/jobs/:id/fix/:rowNumber/:columnIndex` 任务内页面，不增加顶层活动；原值、目标字段和错误在同一个修正上下文可见。现阶段不是表格原位置展开编辑，仍需进一步降低跳转；没有为补齐这一点而修改 Eidos 跨项目通用页面。

## 视觉与颜色

复用 Eidos 原生 Form 的白色商务表面、状态语义、主次按钮和中文提示；警告仅用于真实错误。主要操作“保存修正并重新预检查”；“返回核对”次要。无专属 CSS、配色、模拟/非 Host 研发词。

## 记忆与注意力

系统保存 `rowCorrections`，保留原始值、用户修正、来源列、Job 状态及原 Recipe；刷新/断网后可经原 Job 恢复。用户只需处理标出的记录，不重新填写 22 列。更正后的成功行依然提供撤销入口。

## 无障碍与跨年龄

Enum 用有文字的 select 选项，包含明确选择而非猜测关系角色；依 Eidos 默认焦点、键盘和触控交互。必须实际核实 390px 移动、中文 CJK 字体、文本放大与控件可见范围。不能用代码评审冒称 Human PASS。

## 安全与数据修复

权限：Data Import Human WRITE，Host admission 与真实企业 ACTIVE OWNER/ADMIN 二层校验。源数据不可变，任何修正或撤销都失效旧预检并重新检查；禁止已提交、未映射、已忽略、无关联异常、不可写或非 STRING/ENUM 字段；提交仍有独立授权。旧 revision 防无提示覆盖。AI 不可假扮 Human；仍需环境授权测试。
