# BEX-01 V3 字段映射控件审查（2026-10-29）

## 目标与完成条件

供应商导入的字段核对页在未安装个人代理时不出现 AI 操作。字段表直接呈现来源样本、对应字段、状态与筛选；用户选择“新建字段：列名”后，通过现有主操作进入真正的企业字段审核，再预检查和明确导入。用户要求功能、布局、颜色对照 V3 原型，行高不逐像素追随。真实 Human 签收仍独立进行。

## 流程与步骤

来源：`docs/plans/foundation-list-experience/BEX-01-IMPORT-V3-IN-CONTEXT-HIGH-FIDELITY-20261015.html`，blob `9f57e9320eb527786ff7b737be27777eba6f8a92`。原型 `#mappingRows` 的选项为 `新建字段：` 加来源列名；`#tableFilter` 只负责筛选；`#prepare` 将新增字段带到确认步骤。真实 Host 在 `apps/data-import/page.ts` 生成同语义选项，`apps/data-import/actions.ts` 的 `data-import.review` 保存选择并导航到受权限保护的批量字段审核，审核后再运行真实预检查。原型演示的假自动保存、假提交不移植。

## 导航与信息架构

本页是 Data Import 的任务工作台。未匹配字段的批量审核由当前页主操作进入，单列创建仍可在展开来源证据后按列进入；无需额外“字段处理工具”菜单。已有批次固定值需要再次核对时才出现直接以业务名命名的上下文工具。无个人代理时没有 Agent 按钮；启用个人代理时，辅助操作位于表单次级操作区，不占 V3 的字段筛选栏。

## 视觉与颜色

此次不改 Eidos tokens、四列表、状态标签或行高。现有受控映射页色板按已锁定的原型源码：页面 `#f5f7fa`、表面 `#fff`、文字 `#172b44`、主色 `#2563a6`、边框 `#e3e9ef`，状态色沿用已审核映射。桌面和手机须在真实页面分别复核，不以源码等值宣称视觉完成。

## 记忆与注意力

选项直接显示“新建字段：结算方式”这样的结果，避免把“建议”“企业扩展”“集中审核”技术过程塞进单个下拉项。来源样本、全部原始列、已保存映射和异常提示保持就地可见；更改后仍需明确保存和预检查。移除对当前未启用 AI 的说明，减少不存在能力造成的误导。

## 无障碍与跨年龄

保持原生 select、可见标签、键盘焦点、44px 触控规则及 Eidos 紧凑桌面/手机卡片响应式。无 Agent 时不渲染空按钮；按列链接仅在有创建资格时提供。桌面中文与 390px 真实截图尚未取得，不能记 PASS。

## 安全与数据修复

个人代理入口由 Host 当前启用的 `ENTERPRISE_AGENT_FEATURE_ID` 决定；仅有静态 Agent action 声明不再使按钮出现。字段创建仍受 Object Extension 启用状态和当前企业 Owner/Admin 资格约束。`__CREATE__` 仍是提案，`data-import.review` 不直接创建字段或导入记录；原 Excel 行、忽略选择和待处理列保留。失败可返回映射页修正。

## 页面模式与导航归属

Eidos Page Archetype：任务工作台与四列表字段审核。导航层：导入任务内的 contextual work，不新增 app-domain 或全局入口。唯一主要操作：保存映射并继续预检查；如有待新增字段，先进入真实的企业字段确认。Agent 是可选次级能力，不是完成导入的前提。

## 入口、退出与恢复矩阵

| 身份/状态 | 入口 → 操作 → 目标 | 返回父级 | 取消/异常恢复 |
| --- | --- | --- | --- |
| 企业 Owner/Admin，有待新增列 | 导入任务 → 选“新建字段：列名” → 保存映射 → 批量字段确认 | 确认页可返回映射任务 | 未确认不创建字段、不写入供应商；原始列保留 |
| 普通成员/无创建资格 | 导入任务 → 查看来源/选择现有字段 | 返回导入中心 | 不提供创建选项；未决列不能静默跳过 |
| 无个人代理 | 导入任务 → 字段筛选/人工映射 | 返回导入中心 | AI 操作不显示，主流程照常可用 |
| 已启用个人代理 | 导入任务 → 次级 Agent 操作或人工映射 | 可回映射任务 | Agent 建议不直接提交业务数据 |

入口：`/data-import/jobs/:id/map` 的真实 Host 页面。

退出：返回导入中心，或经过字段确认与预检查到导入结果。

异常恢复：待处理列、权限拒绝、字段审核取消均保留任务与原始来源；相关路径由同 PR 回归测试覆盖。
