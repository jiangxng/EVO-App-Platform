# BEX-01 V2 导入界面：Eidos Human UI 必检记录（研究原型）

> 本次是 **设计研究与交互原型，不是业务功能 PR**；原型源文件 `docs/plans/foundation-list-experience/BEX-01-IMPORT-V2-COGNITIVE-PROTOTYPE-20261015.html`。待 Human 评审，不声称上线或真实 Host 已测试。完整证据见 [BEX 简短交接](../plans/foundation-list-experience/BEX-01-UI-RESEARCH-HANDOFF-ENTRY-20261015.md) 和 [详细资料索引](../plans/foundation-list-experience/BEX-01-UI-RESEARCH-DECISION-REFERENCE-INDEX-20261015.md)。

## 目标与完成条件

业务人员把 Excel 里的供应商资料安全导入，不需要记住每个字段设置，也无需理解 Import Job/Recipe/技术 ID。体验完成意味着历史映射尽可能自动恢复、剩余例外可处理、合法字段确认后可预检查并显式提交、错误能追溯修复；当前 V2 仅为这些目标的交互原型。

## 流程与步骤

推荐用户可见两阶段：上传、核对并导入。同一核对页面内切换建议/预检查/提交状态；保留批量扩展字段创建前的人类确认和最终供应商写入确认（两种副作用不能合并）。强制手动选 22 次字段不合格，已知/高频确定性工作应由直接操作或系统预填承担；AI 只协助不确定的映射。

## 导航与信息架构

遵循 Eidos Navigation & IA；供应商导入是上下文工作，不增加主导航或系统 Settings。原文件名与源对象保持可见，UUID/技术细节折叠。来源与修改同屏，不依赖跳 22 个“为本列新建字段”页面。

## 视觉与颜色

沿用 Eidos Business Office Visual Language：柔和中性画布、白内容面，品牌蓝用于主要操作/选择，状态色只用于真实状态。视觉主线按文件→已处理摘要→待确认异常→唯一主操作；全部来源列按需展开为紧凑表格，拒绝重复大下拉和多层彩色卡片。示例 HTML 的个别数值为候选，不覆盖 Eidos 正式 token。

## 记忆与注意力

默认复用之前有权保存的映射，用户看到来源列名/系统建议/原先决定/原始样本/需要做什么；操作可保存，离开/中断后恢复；已明确忽略可以撤销，不让用户自己背诵 22 列。W3C COGA 为辅助指导，Cowan 四组块不被简化成按钮数量上限。

## 无障碍与跨年龄

不是分“老年模式”，而是对所有人默认可读、可理解、可触达；可缩放正文、明显焦点、键盘访问、图标有文字、状态不只靠颜色。初步设计需在桌面、窄屏、中文、200%/400% 放大测试；本静态原型不是完成无障碍验证的证据。

## 安全与数据修复

原 Excel 所有来源数据留存。未经明确许可不自动创建每个扩展字段，不因导入供应商而伪造 `subjectType`；历史两个同名“开户银行”须显示歧义，不能默认归并或删除。权限、dry-run 与显式提交继续存在，导后修订必须保留审计。
