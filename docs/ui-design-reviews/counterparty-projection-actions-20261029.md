# 客户与供应商列表的页级操作归属

## 目标与完成条件
企业用户进入“客户”或“供应商”列表时，页内只出现与当前列表有关的操作。具备管理权限且导入目标有效时，两页都能直接发起相应关系角色的导入；普通成员仍只能查看获授权记录。用户本轮五张截图显示当前四个跨列表按钮重复了左侧应用导航，侧栏又把“我的…”和“往来对象”与主业务列表并列，且只有供应商页有“导入”。

## 流程与步骤
页面模式是现有 Eidos `catalog-browser` 的表格列表。入口：应用侧栏的客户/供应商 → 当前列表搜索、排序、查看记录，或切换“只看我负责的” → 可返回“查看全部客户/供应商” → 有权限时从主列表“导入” → 已有数据导入工作流 → 返回相应列表。客户导入预设 CUSTOMER，供应商导入预设 SUPPLIER；导入工作流仍允许用户核对和独立确认，不在列表页直接写入。我的客户/我的供应商是责任范围视图，不呈现可能导入到更大范围的页级动作。

## 导航与信息架构
侧栏保留两个日常业务入口“客户”“供应商”。“我的客户/我的供应商”是各自列表的责任范围切换，留在本页就近操作；它们仍有可重载深链和 Workbench 个人工作入口。“往来对象”是统一身份目录，可由应用默认路由、详情返回和搜索访问，但不与两个日常列表并列占用侧栏。`apps/counterparty/page.ts` 的四个页级跨列表按钮删除，换成当前列表的单个范围切换。“数据导入”改名“导入中心”：已登记的往来对象、物料和仓库目标与跨对象任务历史同在这里，不声称可以任意导入所有数据。中心是跨对象任务入口；客户/供应商页只给当前对象就近入口。物料已有就近导入，仓库目前通过中心进入。

## 视觉与颜色
沿用 Eidos 表格列表及其默认按钮、间距、字体和语义色。本次不新增 CSS 或图标。页级唯一显著动作仅在获授权且目标有效时为“导入”；无权限时没有伪按钮。桌面与窄屏均由既有 Eidos renderer 重排。

## 记忆与注意力
列表标题与面包屑明确当前关系角色；责任范围切换使用已有可重载路由，返回“全部”不需浏览器历史。导入路由保留该角色参数，上传及完成返回时无需重新选择客户或供应商。搜索、分页和排序继续由原有路由查询承载；用户不需记住跨列表按钮对应的目标。

## 无障碍与跨年龄
侧栏从六个入口收敛为“客户”“供应商”“导入中心”三个，页内少四个重复按钮，键盘焦点和窄屏操作负担降低；范围切换、“导入”和表格动作由 Eidos 标准组件处理可见焦点、中文标签与触控。真实手机、文字缩放与读屏器测试仍须单独取得。

## 安全与数据修复
`manager/server.ts` 继续从真实企业关系推导 OWNER/ADMIN 管理资格，且仅在目标实际有效时发出导入路由。页面只声明入口；上传、预检查、确认提交、权限拒绝、恢复和审计仍由现有 Host 与导入目标负责。普通成员或目标缺失时不展示入口；不会因 CUSTOMER/SUPPLIER 预设越过导入的独立确认。

## 证据与剩余问题
用户提供五张当前客户/供应商/侧栏/导入中心/往来对象截图；源码 `apps/counterparty/page.ts` 目前无条件输出四个跨列表按钮，`manager/server.ts` 仅给供应商及我的供应商注入导入路由；`apps/counterparty/import-target.ts` 已支持 CUSTOMER/SUPPLIER 和各自返回列表。`apps/data-import/package.ts`、`apps/data-import/page.ts` 提供跨对象目标选择与任务历史，当前代码注册往来对象、物料、仓库/库位三个目标，实际可用集合还由安装/激活状态决定；旧任务在目标停用时用业务说明代替原始技术 ID。国内金蝶官方手册分别把[客户](https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AE%A2%E6%88%B7)放在销售基础资料、[供应商](https://help.open.kingdee.com/dokuwiki_std/doku.php?id=%E4%BE%9B%E5%BA%94%E5%95%86)放在采购/基础资料；用友[客商档案](https://u8chelpcenter.yonyoucloud.com/help/simpchn/10080806.html)和 SAP [Business Partner Role](https://help.sap.com/docs/SAP_S4HANA_CLOUD/f86dc2eb1f8b48c880a7607213104b27/981e51b7ed7349c693d54587acf3b2a4.html)支持同一主体有客户/供应商角色；Microsoft [Business Central 列表筛选](https://learn.microsoft.com/en-gb/dynamics365/business-central/ui-enter-criteria-filters)把 My Customers/My Vendors 作为范围筛选。选择是结合 Eidos 单一导航归属规则作出的本项目推断，不照搬这些产品的界面。`npm run build`、30 项定向 Node 测试、7 项 Host/Eidos 集成测试、`npm run experience:validate` 均 PASS。当前会话浏览器访问被安全策略拒绝，桌面/窄屏实测及 Human 签收待用户刷新后确认，不能以测试代替。

## 页面模式与导航归属
客户/供应商使用现有表格列表 Page Archetype，属于应用域日常工作；“我的…”是责任范围投影，不单独占侧栏。“往来对象”保留统一身份目录和应用默认路由，不单独占侧栏。导入中心是跨对象导入和历史恢复工作台，保留独立入口；对象页导入是就近动作。本变更没有新增页面或路由，只收敛已有导航贡献和名称。

## 功能、布局、颜色对照
功能：当前缺客户导入，补 CUSTOMER 预设并保留导入独立确认；供应商既有导入保留；责任范围视图去掉误导入口并提供返回全部；导入中心继续列出有效目标与历史。布局：侧栏只留两个业务入口及一个跨对象中心，移除页内四个跨列表按钮，当前列表最多一个范围切换和一个授权导入。颜色：不改 Eidos tokens/CSS。三轴代码层面可测，真实桌面/移动状态待验证，Human 状态待签收。

功能：客户/供应商的导入和范围往返通过 Node 回归；真实浏览器待验证。
布局：侧栏三入口和列表单个范围切换由模型回归验证；真实桌面/窄屏布局待验证。
颜色：沿用 Eidos tokens，没有新样式；真实渲染待验证。

## 入口、退出与恢复矩阵
入口：侧栏客户/供应商 → 搜索/排序/详情、切换只看我负责的，或有权限的导入。退出：我的视图可回全部；详情及导入完成通过既有上下文路径返回当前列表；导入取消从上传页返回当前列表。异常恢复：无管理权限或导入目标缺失时隐藏导入；非法角色参数由既有解析拒绝；失败的导入仍留在原工作流供修正重试。回归测试覆盖两类角色、目标缺失、普通成员和往返路由；真实 Host 错误操作待浏览器验收。

入口：客户/供应商在侧栏进入对应列表，定向测试验证路由。
退出：责任范围可回全部；上传页与完成页沿原导入目标返回对应列表。
异常恢复：权限不足或目标未启用时隐藏导入；失败导入保留映射与返回路径。
