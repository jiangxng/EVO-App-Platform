# 企业内容库命名与业务字典管理入口

状态：设计和代码评审进行中；真实桌面、手机和 Human 签收待取得。变更 UI 源码包括 `apps/enterprise-context-governance/package.ts`、`apps/enterprise-context-governance/context-page.ts`、`apps/business-dictionary/page.ts`。

## 目标与完成条件

企业管理者能识别“企业内容库”是当前企业的独立内容和结构容器；业务字典仍是使用该容器的独立插件。已安装字典插件后，企业成员能看字典及字典项，OWNER/ADMIN 能新增或修改字典项，保存草稿后明确发布。发布后其他基础对象字段才能按版本引用。未安装、非企业上下文和无管理权限不能绕过 Host。

## 流程与步骤

企业选择与创建入口沿用原企业上下文应用，只改名称与说明，不改变企业 ID、权限或存储。字典管理采用现有 Eidos 管理列表与表单：字典列表 → 字典详情及选项状态 → 新增/编辑一个选项 → 保存草稿返回详情 → 人工发布并刷新详情。创建字典时录入名称、稳定编码和第一个选项；不要求在普通表单填写 JSON。失败后保留已发布版本与既有草稿，并显示可重试错误。

## 导航与信息架构

“企业内容库”是企业范围和容器名称；“业务字典”是独立安装的业务管理目标。业务字典只有一个应用内入口，不在企业内容库、设置和侧栏重复放置同一路由。字典详情及编辑使用上下文导航返回父级。名称是 UI 标签，技术标识和路由保持兼容。

## 视觉与颜色

复用 Eidos Catalog Browser 的紧凑管理列表、原生表单和 Business Office token；字典状态用文字加语义色，唯一主操作用于新增/保存或发布所在范围。字典项编码为辅助信息，中文名称优先。无插件私有 CSS 或移动 Shell。

## 记忆与注意力

列表和详情显示当前版本、草稿/已发布状态与已有选项；编辑页预填当前值和版本，不要求记住上一页。逐项编辑减少一次输入大量数据；草稿持久化在企业资源库，刷新和返回后恢复。过期版本拒绝覆盖并允许重新进入最新详情。

## 无障碍与跨年龄

使用 Eidos 标准文字按钮、表单标签、焦点和键盘路径。手机由 Eidos 将列表/表单重排为单列，操作目标遵守 44px 触控规则。中文、文字放大与 390px 实机结果待取得，不预先标 PASS。

## 安全与数据修复

业务字典继续由同企业 Resource Library 保存；插件未激活不提供页面/命令。成员只读，OWNER/ADMIN 才能保存草稿与发布；发布仍要求 Human，复核版本与别名冲突。代码对旧字典无名称数据使用旧编码回退显示，不迁移或删除旧记录。停用字典项代替静默删除；已有发布历史保留。

## 页面模式与导航归属

字典列表/详情采用 Catalog Browser 的管理列表模式，逐项编辑采用 Eidos Form；属于企业业务管理。企业内容库沿用已有企业目录与创建表单。V3 原型是业务清晰度参照，字典没有对应 V3 原型，不复制导入工作台布局。

## 入口、退出与恢复矩阵

| 情境 | 入口与动作 | 退出 | 异常恢复 |
| --- | --- | --- | --- |
| OWNER/ADMIN，新字典 | 应用列表 → 新建 → 保存首项草稿 | 字典详情 → 返回列表 | 编码冲突或版本失效不覆盖旧数据，返回列表重开 |
| OWNER/ADMIN，已有字典 | 列表 → 详情 → 添加/编辑选项 → 保存 → 发布 | 详情/编辑均可返回父级 | 版本冲突重载当前版本；别名歧义保留草稿待修 |
| 企业成员 | 列表 → 详情只读 | 返回列表 | 直接构造写命令仍由 Host 拒绝 |
| 个人空间、未安装或停用 | 入口不生效或提示选择企业 | 返回企业目录 | 无权或失活时不读写字典资源 |

入口：已安装字典应用的唯一管理入口与当前企业。
退出：详情和编辑均有 Eidos 上下文返回路径。
异常恢复：草稿留在企业资源库，版本冲突后重载详情再编辑。
