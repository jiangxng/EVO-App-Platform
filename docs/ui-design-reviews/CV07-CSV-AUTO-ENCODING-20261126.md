# CV07 — CSV 自动识别专项 Human UI 评审

## 目标与完成条件
2026-11-26 Human 截图指出手动选择编码增加使用难度。取代 #1390 默认严格 UTF-8、显式 GB18030 的交互决定；保留严格解码与重复表头拒绝。正常用户只选择文件即可继续。
## 流程与步骤
选择文件 → 默认自动识别 → 读取与映射 → 预检 → 独立确认 DRAFT → Human 发布。CSV 优先严格 UTF-8，解码失败才尝试严格 GB18030；XLSX 忽略编码设置。可手动覆盖，不能可靠读取则提示另存 UTF-8。
## 导航与信息架构
不改变通用 Data Import 入口、目标、映射、预检、返回路径或业务字典 Owner。
## 视觉与颜色
复用现有 Eidos 原生 select、原生主题及单一主按钮，默认显示“自动识别（推荐）”，PC 优先，不新增布局。
## 记忆与注意力
编码属于可选恢复设置，正常无需操作。有效 UTF-8 优先；双重有效但文本不同的无 BOM 字节无法仅凭编码规则绝对判定，保留手动覆盖。不得宣称支持所有编码。
## 无障碍与跨年龄
保留原生键盘、触摸、可读中英文标签；正常路径不要求理解编码术语。真实 PC/手机待验。
## 安全与数据修复
严格解码，不用 replacement；UTF-8 BOM 优先且错误时不降级，UTF-16/32 BOM 明确拒绝；真正重复表头或解析失败不触发另一编码重试，失败不创建 Job。保持原鉴权、容量、staged cells、预检零业务写入、独立 Human 发布与主键确认，不推断父子关系。
## 证据与剩余问题
#1390 原始诊断与 #1391 最终交接保持有效。新回归使用合成 GB18030 七列、ASCII/UTF-8/BOM/双重有效字节/不可解码/真实重复，上传 action 不传编码及 AUTO 的映射与零业务写入；原 XLSX 回归保持。真实 CSV 不入库，本次未重新取得原件，CI/部署/Human 均待核验。
## 页面模式与导航归属
沿用数据导入中心上传表单，不改 Host/Eidos 或业务插件专有控件。
## 功能、布局、颜色对照
功能：默认自动识别，显式 UTF-8/GB18030 仅用于恢复。布局：保留 Eidos 表单、PC 优先。颜色：原生控件、既有错误区。
## 入口、退出与恢复矩阵
入口：业务字典或其他已启用导入目标。退出：映射与原返回路径。异常：手动选择编码或另存 UTF-8；重复表头明确列号，不吞列。
