# BEX-01 确认新增字段页面风格校正

## 目标与完成条件

企业导入操作人在确认新字段时，以 V3 已认可的顺序看到任务标题/阶段、当前文件、确认面板、来源列/字段名/类型和底部返回/确认。真实 Host 仍决定字段创建和预检查，不能因视觉调整自动导入业务记录。

## 流程与步骤

保留映射 → 确认新增字段 → 预检查 → 独立提交的已验证旅程。本轮改页面表达：确认面板内一次核对并前进，返回仍到同一任务映射。上轮只加三列表格与配色变量，未形成 V3 的组合结构，是当前截图差距的根因；本轮改用 Eidos 确认面板能力，而非继续微调表格行高。

## 导航与信息架构

页面仍属导入任务的 contextual 步骤，Eidos Form / Review Table confirmation 模式。面包屑、阶段和原有路由保留；没有新菜单或重复入口，唯一主操作为“确认创建并预检查”。

## 视觉与颜色

固定原型 `docs/plans/foundation-list-experience/BEX-01-IMPORT-V3-IN-CONTEXT-HIGH-FIDELITY-20261015.html` blob `9f57e9320eb527786ff7b737be27777eba6f8a92`：`#confirm > .panelbody` 内有 h2、说明、三列表格和带分隔线的 actionbar；前方 `.fileinfo` 有 XLSX 图标、文件名、工作表/行列数及绿色已读取状态。原型底色 `#f5f7fa`、白面板、文字 `#172b44`、次级文字 `#6a7c91`、边框 `#e3e9ef`、主蓝 `#2563a6`。当前色变量已有，但缺语义结构。Eidos 通用能力负责面板与控件样式，Platform 仅提供真实文件事实和页面文案；不追求逐像素行高。

## 记忆与注意力

文件名、工作表和行列数就地呈现，避免操作人跨屏回忆。表格只列待新增项，当前类型可直接修改；返回映射后保留保存的 Import Job，失败仍可修正。

## 无障碍与跨年龄

保留原生表格列头、Select 标签、焦点与键盘顺序。窄屏用 Eidos 表格重排和至少 44px 的选择/操作，状态同时使用文字而非只靠绿色；文本缩放不裁切关键操作。

## 安全与数据修复

文件读取状态只来自已保存的 staged Import Job，不虚构新读取事件。创建字段仍校验企业管理权限、任务修订和幂等，预检查后才允许单独提交导入；失败返回映射可恢复，不改原始文件。

## 证据与剩余问题

用户提供的两张真实界面截图证明旧页面的视觉差距，V3 源码给出结构/色值/状态。根因是 `apps/object-extension/batch-page.ts` 缺文件图标、读取状态、工作表和 `reviewTable.heading`；`vendor/eidos/src/renderers/html/index.ts` 把确认表格与 footer 分开，`vendor/eidos/src/design-language/productive-workbench-css.ts` 仅加局部配色。上轮路径只调三列与 token，没有解决结构。本轮 Eidos PR #207 已合并（`c8b3072b`），Platform 仅移植通用确认面板差异并提供业务事实。Eidos 18/18 设计语言测试、Platform 24/24 关联协议测试和两仓编译通过；最终 HEAD 桌面/窄屏 CI 及 Human 签收仍需单独确认。

## 页面模式与导航归属

Eidos Form / Review Table confirmation；导入任务内 contextual，不进入全局导航。确认面板提供一个局部决定区域，前方文件卡片提供来源事实；页面主标题和阶段仍归 Eidos 工作台。

## 功能、布局、颜色对照

功能：V3 返回核对、修改字段类型、确认后预检查；真实 Host 已有相应路由和权限，本轮不改命令。

布局：当前只有文件文字卡、三列表格和独立页脚；目标是 V3 文件标识/读取状态与一体化确认面板（标题、说明、表格、操作区）。

颜色：复用已锁定的 V3 局部变量及 Eidos Business Office tokens，白色面板/浅色画布/蓝色主操作/绿色真实状态；不建立插件私有主题。

## 入口、退出与恢复矩阵

| 状态 | 入口 → 操作 → 目标 | 返回父级 | 取消/异常恢复 |
| --- | --- | --- | --- |
| 有管理资格且映射完整 | `/map` 保存 → 确认新字段 → 创建并预检查 → `/review` | `← 返回核对` 到同一任务 `/map` | 失败后仍保留任务、文件、已保存映射 |
| 仍有未决列 | `/map` → 完整批次审核 | 返回 `/map` | 不跳过未决列 |
| 无管理资格/个人上下文 | Host 拒绝无权创建 | 返回导入目录 | 不生成字段或业务记录 |

入口：现有 `/object-extensions/from-import?job=…&mode=confirm`。

退出：返回核对或进入同一任务的真实预检查结果。

异常恢复：沿用原任务和权限/预检查失败路径；本轮只改变界面表现。
