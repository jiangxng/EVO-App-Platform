# BEX-01 V3 示例值单元格纠正（2026-10-29）

## 目标与完成条件

用户在真实 `localhost:4100` 截图中指出“▶ 查看来源样本”仍出现在示例值旁。批准的 V3 HTML 表格只显示一个示例值，不提供此行内展开按钮。本轮在 `apps/data-import/page.ts` 移除映射表所有来源样本展开项，保持原文件、映射与审批安全边界。

## 流程与步骤

直接核对固定原型 `docs/plans/foundation-list-experience/BEX-01-IMPORT-V3-IN-CONTEXT-HIGH-FIDELITY-20261015.html` blob `9f57e9320eb527786ff7b737be27777eba6f8a92`：`fillMappings()` 用 `two.textContent=sample` 生成示例值，没有详情按钮。真实 Host 的四列表继续显示来源列名、单个示例值、系统字段下拉和状态。选“新建字段：来源列名”后仍通过主操作进入授权批量字段确认。

## 导航与信息架构

此页是导入任务工作台，不为“查看来源样本”增加独立导航。上次 #1141 已移除泛化字段工具菜单；本轮移除仍藏在来源详情里的单列新建按钮，使字段核对保持 V3 的直接四列表。单列创建的受保护旧深链仍可处理历史链接；普通用户的可见创建路径为选择新建字段并继续。

## 视觉与颜色

移除每行蓝色链接及三角形，示例值只呈现原型的辅助文字。沿用 Eidos 已批准的白色表面、`#6a7c91` 示例值及状态色，不改全局 tokens、列顺序、响应式语义或强制行高。真实桌面和手机渲染待最终 HEAD 浏览器证据。

## 记忆与注意力

一行一个来源示例，用户无需判断“示例值”和“来源样本”是否是两份不同数据。完整来源行仍留在有权限的持久导入任务内，选择“不导入”也不会删原始数据。含两个同名目标的银行字段继续在下拉选项中同时显示稳定 fieldId 和可信用途，保持决策所需证据就地可见。

## 无障碍与跨年龄

删除多余可聚焦控件，保留原生 select、筛选、状态文字及手机卡片排列。来源示例仍是可读文本；空列使用明确的“来源数据为空”。键盘与触控无需多一步展开。实际中文屏幕阅读器与 Human 体验待验。

## 安全与数据修复

真实 `DataImportJob` 的原始表头及行未改变，未改导入保存、预检查、提交和字段创建授权。多候选字段不自动选中；其 fieldId 与用途在系统字段选项中展示。`__PENDING__` 仍不能静默跳过。去掉的是映射表的展示详情，不是来源数据或审核逻辑。

## 入口、退出与恢复矩阵

| 身份/状态 | 入口 → 操作 → 目标 | 返回父级 | 取消/异常恢复 |
| --- | --- | --- | --- |
| 有导入权限，普通字段 | 导入任务 → 直接读示例 → 选系统字段 → 预检查 | 返回映射或导入中心 | 无保存时可恢复初始选择；原文件不变 |
| Owner/Admin，待新增字段 | 映射页 → 选新建字段 → 主操作 → 字段确认 | 确认页返回映射任务 | 取消不创建字段、不导入记录 |
| 同名字段/无资格 | 映射页 → 在下拉中核对 fieldId/用途；无资格不提供新建 | 返回导入中心 | 未决或无权限时拒绝提交，数据仍保留 |

入口：`/data-import/jobs/:id/map`。

退出：返回导入中心或继续字段确认/预检查/导入结果。

异常恢复：原始 Job 保留，待处理和授权失败不写入业务对象；同 PR 测试覆盖核心路径。
