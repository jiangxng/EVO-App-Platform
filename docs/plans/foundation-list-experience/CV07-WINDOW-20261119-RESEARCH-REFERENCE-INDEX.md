2. **“受保护 main@67cf16a...” vs “VPS 运行 702a74e...” 不是发布冲突**：RUN06 是 doc-only skip，RUN04 是真正的 runtime publish；引用运行镜像时使用 \`702a74e...\`，最新代码时用 \`67cf16a...\`。
