# A03 账本发布回执与未知结果

日期：2026-10-15（香港）。平台基线 `f09709adcb1b9817516d8d3c2479845c5900f22b`；远端 EVO 只读核对基线 `d5ce051325c4572c7a5fd713560d7d7d06e4b401`。本批分支 `fix/governance-publication-receipt-20261015`。属于现有 A03，不新增治理任务，不接管 Agent/BEX/2D，不部署。

## 发现与修正

以前 Host 对 burn 的任意 2xx 都直接返回，账本管理随后显示发布成功；正文不是 JSON、企业不符或摘要不符也可能被当作成功。请求及正文消费没有应用层期限。

本批新增账本管理内部适配模块 `apps/ledger-manager/internal/publication-runtime.ts`。Host 在已有授权流程之后动态加载该模块，只传连接地址、已解析的企业映射和编译结果。不新增插件、不扩大 Core、不改共享 evoJson 的其他消费者或旧兼容 API。

- 按实际 EVO 回执核对 `ok`、企业 ID/代码、configurationId、semanticDigest、应用/账本/规则数量、表达式数量、内建函数及应用实例映射。
- 企业 ID 映射存在时必须精确匹配 ID；否则匹配本次发送的企业代码。不能拿别的企业回执宣布成功。
- 默认 30 秒应用层期限覆盖请求和正文读取；到期取消请求并结束等待。取消不等于远端事务回滚。
- 仅一次 POST，禁止 HTTP 重定向与自动重试。适配器忽略取消时，迟到结果也不能改变已返回的未知状态。
- HTTP 非成功、网络异常、超时、无效或不匹配回执，均以 `LEDGER_MANAGER_RUNTIME_PUBLISH_UNKNOWN` 返回给既有 Action 错误通路，提示先核实，不直接重复发布。HTTP 拒绝可被识别为 HTTP 错误，但不能从代理响应推断远端绝对未写入。
- 本地参数、授权、确认和编译错误仍在发送前失败；保留原来的错误码和定义版本，不因发布失败而修改定义。

## 方案比较与限制

| 方案 | 决定 / 理由 | 限制 |
|---|---|---|
| 只判断 HTTP 2xx | 排除：不能验证响应属于本次配置/企业 | 代理 HTML 或错误形状可能误报成功 |
| 对实际回执严格校验 + 有限等待 | 本批采用：直接解决既有错误成功提示，改动局限在发布适配器 | 是合同校验，不能替代可信远端、实际数据库验证或未来调用健康证明 |
| 超时后查询现有 status 自动判成功 | 排除：没有本次发布标识/摘要，且计数范围不充分 | 企业以前发布过也可能 burned=true |
| 超时后自动重发 | 排除：响应丢失时原事务可能已提交，当前没有幂等键合同 | 重发可能重新写规则，不能以“看起来覆盖”推定无副作用 |
| 新增操作标识、持久回执及查询 | 后续远端 owner 合同方向，未实施 | 需企业隔离、配置摘要绑定、并发/幂等及恢复证据；不在 Host 伪造远端权威结果 |

以上采用/排除是本次工程判断；远端字段与 SQL 范围是源码事实。远端兼容入口没有因此获得新的可信身份边界，现有配置和授权限制仍适用。固定源码不能证明当前运行部署与其一致。
