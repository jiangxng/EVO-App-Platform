# GOV-02 管理页面接入

2026-10-13，基于main `c2e8dcc0`；独立分支`feat/governance-provider-lifecycle-ui-20261013`。

Provider管理入口增加“运行与清理”，路由`/providers/lifecycle`。使用既有eidos settings-editor与catalog-browser列表，不新增独立应用或修改eidos副本。

- 页面初始只显示管理员验证表单，凭据为空，不在页面定义暴露运行状态。进入页面不会加载或启动Provider。
- 查询复用上一批受授权保护的生命周期API，凭据仅存在当前输入控件及请求过程中，不写localStorage/sessionStorage、不拼接URL、不返回到服务端页面定义。
- 状态与进行中的调用数量按列表展示。STOP_FAILED可重试；STOPPING/STOP_TIMEOUT可继续等待原清理任务。其他状态禁用，服务端仍执行独立的状态和权限检查。
- 清理完成、等待超时、失败、网络/权限问题有明确反馈；操作期间防止重复请求，查询/清理请求均设35秒客户端等待上限。超时不承诺服务端清理停止。
- 查询按钮可手动刷新；不启动持续轮询任务。离开页面后的响应不再更新界面。
- 界面复用eidos响应式表单/列表与按钮，中文/英文随界面语言显示，其余语言暂回退英文。包标识原样展示，所有渲染经过eidos文本转义。
- 管理交互代码只在表单提交时动态加载。该表单由Host客户端专属处理，不提交到保存Provider绑定的命令。

协议/渲染测试覆盖空凭据、未授权前不暴露状态、可重试状态组合、文本转义；已有Provider绑定/本地化、管理API授权测试继续通过。轻量CI纳入页面测试，静态提前加载业务依赖保持297条。
