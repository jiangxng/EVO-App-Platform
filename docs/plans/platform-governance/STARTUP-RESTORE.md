# GOV-01 启动恢复首批治理

2026-10-13。基于 `b47cf93006e2a8d92617a9c92af94a608773bcc3`，继续PR #794。此轮修改运行代码，未部署；不把一次性初始化修复称为已完成按需装载。

## 问题与范围

此前宿主每次启动都可能根据“缺少包”重新安装业务默认包；3D运行图及企业观测还按Feature未激活判断，可能覆盖已停用状态。

首批范围：`evo-eog-3d`、`evo-enterprise-observatory`、`eog-bottleneck-analysis-provider`、`evo-counterparty`、`evo-object-extension`、`evo-data-import`。

## 当前行为

宿主使用 `manager/startup-defaults.ts` 执行一次性默认安装。初始化凭据存放在生命周期状态文件同目录的 `startup-defaults.json`，单独使用现有原子文件存储，不混入插件可编辑设置或业务数据。

- 已安装：记录已处理，不重新启用其Feature。
- 尚未安装且未记录：保持兼容默认安装；依赖条件不满足时暂缓。
- 安装成功：记录完成。安装失败不记录，下次可重试。
- 已记录：重启不再执行该默认安装；后续停用、卸载选择可保留。
- 无持久化生命周期文件：初始化记录也只在内存中，重启仍视为新实例，不能承诺保留安装选择。

`startup-defaults.json`须与生命周期状态一起备份/恢复。它与现有JSON文件存储一样面向单宿主写入；不新增多副本一致性承诺。回滚旧版本宿主会恢复旧自动安装行为，应先备份状态，不能把回滚当作保留用户选择的保证。

## 验证

构建通过。3项新测试覆盖已安装保持不变、条件不足暂缓、失败后重试、跨初始化实例只执行一次，以及真实宿主的三次启动：

1. 空白状态按原行为安装默认包。
2. 在持久化夹具中停用这6个包，并移除初始化记录模拟旧实例升级；重启仍保持停用。
3. 移除这6个包的持久化安装记录；重启不补装，托管登录仍在。

集成测试使用隔离临时状态、禁止TCP外连、真实宿主启动/退出。持久化夹具用于验证恢复逻辑，**不是通过公开卸载API完成的依赖/授权验收**。CI已加入同一测试。

## 明确未覆盖

- 历史版本没有记录卸载意图。已有实例若包缺席且无初始化记录，本轮仍会兼容性初始化一次；不能推断它此前是否被用户卸载。
- 只阻止本轮六项直接默认安装。其他新装插件的必需依赖仍可能要求这些包，需由安装影响预览及依赖规则治理。
- 后续批次已覆盖BI、2D历史迁移、账本切换、应用运行时绑定和个人记忆默认安装；身份/授权及显式远程Provider配置沿用原安全规则，见下节。
- 默认compatible仍保留兼容业务组合；新增minimal安装模式见下节。业务实现的提前导入尚未治理，静态遗留依赖边仍299条。

下一步：逐项区分强制安全基础、显式操作员配置、一次性升级与可选默认包；为最小启动模式和剩余迁移建立测试矩阵，再处理资源激活/释放。

## 第二批：显式最小安装模式及剩余产品迁移

配置：`APP_PLATFORM_STARTUP_PROFILE=minimal`，同时必须设置 `APP_PLATFORM_MANAGED_SESSION_ENABLED=true`；缺少托管会话或模式拼写错误会启动失败，不降级为匿名模式。未配置时仍为`compatible`。

| 情况 | 当前行为 |
|---|---|
| 新实例minimal | 跳过隐式业务默认包、个人记忆默认包，以及2D/账本/运行时绑定历史自动切换 |
| 既有实例改minimal | 保留已有安装和持久化数据，不自动卸载；不是清理指令 |
| minimal后改compatible | 尚未执行的兼容默认安装可以执行；属于显式模式变更 |
| 显式BI AUTOINSTALL=1 | 两种模式都尊重操作员明确选择，但只初始化一次，不再每次补装 |
| 配置远程Provider/身份相关能力 | 继续沿用明确配置及既有安全规则，minimal不取消安全检查 |

纯净minimal实测7包：托管登录、身份目录、授权、企业上下文、上下文授权、企业关系、External Agent治理。没有往来对象、导入、图形业务或个人记忆默认包。此数量只适用于本报告的无额外操作员配置环境。

2D设计器切换使用版本化一次性迁移记录。已经满足目标也记录完成，避免用户以后停用又被当作历史迁移重新启用。该检查移至默认安装之后，兼容模式新实例在同次启动完成原本可能延至第二次启动的设计器切换。无历史记录且只有Viewer活跃的旧实例仍执行一次兼容迁移，无法追溯它是否属于旧的主动停用。

账本管理切换、应用运行时绑定、个人记忆默认包均接入一次性初始化机制；已安装的运行时绑定不再因停用而被强制启用。2D业务实现与交互没有修改。

新增测试覆盖：minimal保留安全基础包，未登录`/auth/session`返回401、主页引导登录，重启安装列表不变；无托管会话/非法模式拒绝；迁移失败重试及完成后不重复；真实宿主2D设计器停用后重启仍停用且Viewer保留。构建、7项启动专项及16项相关回归通过。
