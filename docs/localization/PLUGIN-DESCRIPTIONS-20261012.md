# 插件卡片用途说明（中文先行）

日期：2026-10-12（香港时间）。承接标题本地化 PR #757。

用户要求：在插件卡片折叠详情中提供不超过 50 字的用途说明，其他语言暂时共用中文。

## 实现与边界

- 42 个静态 Package 和 6 个可选演示 Package 各有用途说明；不改变目录可见性。
- 说明由各插件清单的可选 `description` 字段持有，未安装、停用时仍可读取。
- 平台把说明传给 Eidos `detailsDescription`；原有卡片统计行保留，用途说明位于默认折叠详情顶部。
- 所有语言直接共用中文源字符串，无重复翻译副本、无模型翻译调用；后续按包添加说明翻译元数据和解析即可。
- 50 字上限按 Unicode 码点计数，对本批内置文案自动检查；不是对所有第三方协议文本强加长度限制。
- 旧清单可不提供说明；提供时须为非空字符串。TypeScript、JSON Schema 和语义校验同步。
- 六个演示明确标注合成数据、只读；财务核验保持只读，不暗示执行授权。

## Eidos 归属

通用折叠区纯文本渲染已提交 Eidos PR [#175](https://github.com/jiangxng/eidos/pull/175)，提交 `7b346ca60d1c5fc9922c9010951f37463258cc78`。
平台仅固定采用该组件，`vendor/eidos/source.manifest.json` 记录独立来源，不同步其他组件与其他窗口的 Host overlay。新增字段转义 HTML，不允许插件注入标记。

## 验证与接续

本地：两仓 TypeScript 编译通过；平台标题/描述/协议测试 13 项通过；Eidos Extension Manager 测试 9 项通过；平台 Experience 与 Design Language 门禁通过。
验证包含全部 48 项文案长度、四种支持语言及未知语言中文回填、默认折叠位置、旧清单兼容、无效字段拒绝、HTML 转义。
