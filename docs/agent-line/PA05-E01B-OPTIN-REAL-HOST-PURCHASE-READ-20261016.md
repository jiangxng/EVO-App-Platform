## Engineering choice and safety

Implement only a *bounded Host wiring option*, without an alternate Registry. The trusted Host environment setting `APP_PLATFORM_PA05_E01_PURCHASE_ATTENTION_HOST` defaults to `OFF` and accepts only `OPT_IN` or `OFF`. Unknown values fail startup. On `OFF`, do not load the Purchase Attention package/Host adapter module, do not add it to the catalog, do not register a Handler and do not install anything. On `OPT_IN`, dynamically load only the real plugin's Host adapter and add its Manifest to the available Host catalog and one lazy READ handler to the existing Action Router. **An administrator must still explicitly install/activate the package** and its Trading Reference dependency and grant each operation; `OPT_IN` is *availability*, not installation, rights, Human signoff or security bypass.

The plugin-owned [Host adapter](../../apps/purchase-attention/host-optin.ts) delegates to the existing [business Owner](../../apps/purchase-attention/operation.ts) and sends its upstream request **back through the original Host Action Router**. The target and source operations independently check active Feature, tenant, resource policy, and missing/deny Authorization Provider. No write permission, Worker, schema/PKI, new HTTP endpoint, default source mapping or background model invocation is added. An undeployed opt-in configuration is not production routing.

The E01A decision rejected *unapproved default Host registration*. E01B does **not** reverse that: the new code cannot run by default, and administrators/owners must explicitly authorize any future real installation and production configuration. This is a reversible and narrowly scoped engineering adapter, not unconditional installation.

**Alternatives rejected:** unconditional package catalog+default install, direct Owner→EVO bypass of Host authorization, new parallel Action Router/Agent-specific operation namespace, fake primary identity/provider to make CI green, silently guessing enterprise→EVO mapping, making default production WRITE available, or calling two locally constructed identities a real Human/Provider signoff.
