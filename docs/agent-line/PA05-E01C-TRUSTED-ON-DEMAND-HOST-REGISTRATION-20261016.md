## Decision and implementation

Add the minimum generic trusted **late registration operations** to the *same* `PackageCatalog` and `AppActionRouter`: `register(manifest)`, `hasHandler(commandCode)`, `registerHandler(handler)`. They fail on duplicate entries and do not replace installed owners or grant permissions. The original Manager installation and original Router invocation path remain authoritative.

An independent [`manager/on-demand-host-read-admission.ts`](../../manager/on-demand-host-read-admission.ts) is host-composition-only. It takes an **already trusted, injected** Host authorization callback and a caller-owned deferred module loader (no arbitrary user supplied import path, no HTTP registration API). On admission: (1) authorize before module import; (2) reject pre-existing package/command; (3) lazy-load; (4) **reauthorize after await** to reject consent revoked during import; (5) validate actual Plugin Protocol manifest, exact expected package/one READ Operation with Human and Personal Agent exposure, exact Action Host binding/version, handler package/Feature/command/function; (6) synchronously register into original catalog/router after a final duplicate check. Concurrent callers cannot bypass their own initial authorization. Do not install or activate the package automatically: installed/active Feature and source permission checks still run in the existing code before business read.

This closes the generic on-demand registration gap **in a directly reusable, isolated Host composition** without modifying `manager/server.ts`, introducing startup imports, adding privileged endpoints or granting Agent code the ability to register providers.

**Rejected:** startup unconditional or `OPT_IN` dynamic import (actual ratchet failure), a second plugin router, auto-install with forged Human approval, allowing extra WRITE operations in a supposed READ plugin, handler replacement on collisions, manifest-declared authorizer, serializing authorization into prompts, or treating a test Provider as real User/Provider approval.
