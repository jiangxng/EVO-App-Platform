## Decision and exact scope

**Adopt:** still use the one original Object Extension Owner, actual D10 ticket, PA-02 INVOKING/UNKNOWN, immutable Host command, D14C6 role drift, D14C7 revoked/consumed lock and D14C8 full approved resource/evidence. Add protected `bound_backend_pid` and `bound_transaction_id` to the **same** opt-in SQL Host permit row. The original Owner begins the real SQL transaction and forces a real 64-bit transaction ID with `pg_current_xact_id()` **before** asking independent Host to issue and bind a permit. A **Host SQL LOGIN-only** `SECURITY DEFINER` function resolves `pg_stat_activity` against the real Business LOGIN OID, database OID, backend PID and assigned backend_xid and pins the permit to that active transaction. It is idempotent only for the exact same backend and xid; rebind attempts to a different live transaction fail closed. The physical business INSERT trigger checks `pg_backend_pid()` and `pg_current_xact_id_if_assigned()::text` against the Host-protected permit while retaining all prior D10/source/payload/freeze gates. The original Owner idempotent consumed-receipt read is retained; a 32-hex no-write sentinel cannot bind a new material write.

**Important restriction:** no new credential, no duplicate Owner, no production provision or migration, and no claim that the existing business LOGIN represents a protected machine. This rejects cross-**connection** replay even with the same SQL password and token. A compromised original backend, code path, or a Host that intentionally binds an attacker-selected backend is **not** solved. There is no invisible session hijacking prevention once the live original connection itself is controlled.

**Rejected:** depending on backend PID alone (PID reuse), an app/GUC-provided transaction ID without PostgreSQL server verification (spoofing), one-time Host approval before SQL transaction with no physical binding, and falsely equating a scoped Host database LOGIN with production mTLS/workload-attested identity. Do not introduce a second application business engine.
